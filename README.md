# 🛍️ LINEアフィリエイト（お得速報）プロジェクト設計書

## 💡 本資料の目的と開発ゴール
本資料は、LINEでお得なセール情報を配信するアフィリエイト通知システム「お得速報」の設計・開発の全体像を整理した設計ドキュメントです。
本プロジェクトでは、以下の**3つのゴール**を達成することを目的としています。

1. **ユーザーニーズに合わせたセグメント配信の実現**：ユーザーが選択したカテゴリー（お米、飲み物など）の通知のみをシステムが自動判別して届け、無駄な通知をゼロにする出し分けシステムを構築する。
2. **実践的なバックエンド開発の習得**：Pythonを用いたLINE Messaging APIの連携や、ユーザー管理（データベース保存）の仕組みをゼロから構築する。
3. **実用的なサービスの段階的成長**：まずは手動配信とDB保存（フェーズ1）からミニマムにスタートし、将来的にはAPIやスクレイピングを活用した自動化へとスケールさせる。

## 📑 作成の背景 (Background)
現在、InstagramやX（旧Twitter）では多くのインフルエンサーがお得なセール情報を発信しています。しかし、配信されるジャンルが多岐にわたるため、ユーザーにとっては「全く興味のない商品の通知」も大量に流れてきてしまい、結果として通知をオフにしたり、フォローを解除したりするという機会損失（ノイズ問題）が発生しています。

私自身も同様の経験があり、「自分が本当に興味を持っている、購買意欲の高いジャンルの情報だけを厳選して受け取りたい」という強いニーズを実感しました。

この課題を解決するため、ユーザー自身が欲しいカテゴリーだけを選択できるパーソナライズ型のLINE Botを開発することにいたしました。配信を最適化することで、これまで「情報の多さに疲れて、お得情報への関心を失っていたライト層」に対しても的確に商品をアピールし、高い成約率を生み出す新しいアフィリエイトモデルの構築を目指します。

## 1. 🌟 概要 (Overview)
本プロジェクトは、Amazonや楽天市場といった通販サイトのお得情報を手動で登録し、ユーザーが希望するカテゴリー（お米、飲み物など）に応じて対象者へ自動出し分け（セグメント配信）を行うためのLINE Botシステムです。

「まずは手動運用でスモールスタートし、実績や収益が出たら自動化に移行する」という方針のもと、PythonとLINE Messaging APIを用いて開発を進めています。

## 2. 🛠️ 使用技術 (Tech Stack)
* **プログラミング言語**: Python 3.x
* **開発環境**: Eclipse (PyDev プラグイン)
* **バージョン管理**: Git / GitHub
* **外部API / インターフェース**: LINE Messaging API (LINE Official Account Manager)
* **データベース**: SQLite（軽量で扱いやすいため初期開発に採用）
